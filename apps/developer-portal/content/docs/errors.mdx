## HTTP status map

| Status | Meaning |
|--------|---------|
| 400 | Validation / bad request |
| 401 | Missing or invalid credentials |
| 403 | Authenticated but not permitted |
| 404 | Resource not found |
| 409 | Conflict (duplicate slug/install) |
| 413 | Upload too large |
| 415 | Unsupported media type |
| 429 | Rate limited / quota exceeded |
| 5xx | Server / upstream failure |

## Example error bodies

Most 4xx errors from `/public/v1/*` return FastAPI's generic shape:

```json
{ "detail": "Agent not found" }
```

Quota-exceeded errors (HTTP 429) return a structured body instead:

```json
{
  "error": "quota_exceeded",
  "dimension": "total_tokens",
  "current_usage": 50000,
  "plan_limit": 50000,
  "upgrade_url": "/billing"
}
```

`dimension` is either `"spend"` or `"total_tokens"`. Check for `error === "quota_exceeded"`
before falling back to generic `detail`-based error handling.

## JavaScript SDK

```ts
import { THTWAATError } from "@thtwaat/sdk";

try {
  await client.chat("hi");
} catch (e) {
  if (e instanceof THTWAATError && e.status === 429) {
    // backoff
  }
}
```

## REST SDK

```ts
import { RestError } from "@thtwaat/rest";

try {
  await api.agents.chat({ message: "hi" });
} catch (e) {
  if (e instanceof RestError) {
    console.log(e.status, e.code, e.retryable, e.details);
  }
}
```

Fields: `status`, `code`, `message`, `details`, `retryable`.
