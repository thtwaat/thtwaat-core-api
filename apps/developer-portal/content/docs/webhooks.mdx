## Overview

Register webhook endpoints to receive signed JSON payloads for billing, domain, agent, and notification events.

## Create a webhook

The webhook secret is generated by the server and returned **once** in the create
response — you never supply your own.

```http
POST /api/v1/webhooks
Authorization: Bearer <jwt>
Content-Type: application/json

{
  "url": "https://hooks.acme.com/thtwaat",
  "event_types": ["payment.succeeded", "domain.verified", "agent.published"]
}
```

Response (secret shown only this once — store it, it cannot be retrieved again):

```json
{
  "id": "b1f2c3d4-...",
  "url": "https://hooks.acme.com/thtwaat",
  "event_types": ["payment.succeeded", "domain.verified", "agent.published"],
  "is_active": true,
  "created_at": "2026-07-29T10:00:00Z",
  "secret": "whsec_..."
}
```

Use `"event_types": ["*"]` (the default if omitted) to receive every event type.

## Payload shape

```json
{
  "event": "agent.published",
  "data": { "agent_id": "..." },
  "delivery_id": "whdel_9f3a2b1c..."
}
```

Every delivery is a flat JSON object with exactly these three top-level keys — there
is no separate `id`/`type`/`created_at` envelope. `delivery_id` is unique per delivery
attempt; use it as your idempotency key when de-duplicating retries.

## Verification

Every delivery is sent with two headers:

- `X-THTWAAT-Timestamp` — unix timestamp (seconds) at send time
- `X-THTWAAT-Signature` — `v1=<hex>`, an HMAC-SHA256 hex digest of `"{timestamp}.{raw_body}"`
  keyed with your webhook secret

Verify by recomputing the HMAC over the **raw request body** (before any JSON
parsing) and comparing it in constant time. Reject requests where the timestamp is
more than 5 minutes old to guard against replay.

**Python**

```python
import hmac
import hashlib
import time

def verify_thtwaat_webhook(raw_body: bytes, timestamp_header: str, signature_header: str, secret: str) -> bool:
    if abs(time.time() - int(timestamp_header)) > 300:
        raise ValueError("timestamp outside tolerance — possible replay")

    signed_payload = f"{timestamp_header}.{raw_body.decode('utf-8')}"
    expected = hmac.new(secret.encode(), signed_payload.encode(), hashlib.sha256).hexdigest()

    # signature_header looks like "v1=<hex>"
    _, _, provided = signature_header.partition("=")
    return hmac.compare_digest(expected, provided)
```

**Node.js**

```javascript
const crypto = require("crypto");

function verifyThtwaatWebhook(rawBody, timestampHeader, signatureHeader, secret) {
  if (Math.abs(Date.now() / 1000 - Number(timestampHeader)) > 300) {
    throw new Error("timestamp outside tolerance — possible replay");
  }

  const signedPayload = `${timestampHeader}.${rawBody}`;
  const expected = crypto.createHmac("sha256", secret).update(signedPayload).digest("hex");
  const provided = signatureHeader.split("=")[1];

  return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(provided));
}
```

Respond with a `2xx` status quickly (delivery is retried on non-2xx/timeout); do any
slow processing asynchronously after acknowledging.

## Delivery retries

Failed deliveries retry with exponential backoff for retryable statuses (5xx / 408 /
429 / timeouts). You can inspect delivery history and manually retry a specific
delivery via `GET /api/v1/webhooks/deliveries` and `POST /api/v1/webhooks/deliveries/{id}/retry`.
