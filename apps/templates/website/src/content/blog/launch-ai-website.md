## Why this starter exists

Most AI chat embeds force you to rebuild marketing pages from scratch. This template ships Home, Pricing, Blog, Contact, and a full chat experience already wired to THTWAAT.

## Connect in three steps

1. Publish an agent and copy the `tht_live_…` key.
2. Set `NEXT_PUBLIC_API_URL` and `NEXT_PUBLIC_AGENT_API_KEY`.
3. Run `npm run dev` — the floating widget and `/chat` page work immediately.

## Knowledge-aware answers

Attach a knowledge base to your agent in the THTWAAT platform. Public chat uses RAG automatically when configured.
